# LXMusicC

一个轻量 Android 音乐播放器，兼容部分 LX Music 自定义音源，支持搜索、在线播放、离线缓存与后台播放。不内置音乐资源；音源兼容范围与使用限制见下文。

## 功能（1.1.0）

- **四个页面**：歌曲 / 搜索 / 正在播放 / 设置，点击底部页签切换
- **歌曲库**：收藏/取消收藏、最近播放、自建歌单（创建、重命名、增删歌曲、删除歌单）；按歌名/歌手/专辑本地搜索，歌单目录按名称搜索，每页六项；重启后保留
- **系统键盘**：搜索、库内搜索、歌单命名和音源地址默认使用系统输入法，支持中文候选、删除、光标/选区与粘贴；键盘回车搜索或提交，横屏与分屏可输入
- **多源搜索**：输入或粘贴关键词，同时查询全部启用音源；结果按相关度排序并去重，每页八首，展示歌名、歌手、时长、音质与来源；支持取消、错误提示及重试
- **在线播放与后台播放**：点击搜索结果开始播放；支持播放/暂停、上下首、前后跳转 10 秒，显示实际进度与时长；切后台、锁屏或退出界面仍可播放
- **公共目录缓存与离线播放**：在播放页缓存当前歌曲，保存到 `Music/LXMusicC/<音源>/<歌手> - <歌名>.<ext>`；优先播放已有缓存，同曲同音质不重复下载；设置内查看缓存列表、占用，单条删除或清空，设置容量上限
- **播放页**：封面下载与离线复用、缺失占位、可拖动进度条与实际时间；播放队列分页选曲，顺序/列表循环/单曲循环/随机播放，上滑封面展开队列，封面淡入与队列展开动画
- **系统媒体服务**：其它 App、车机可浏览搜索结果、收藏、歌单、最近播放和当前队列，选曲及控制播放/暂停/上下首/进度；通知栏/锁屏和耳机媒体键可用。来电暂时打断后恢复、短暂提示音时降低音量、拔耳机暂停，输出跟随系统；重启可恢复上次队列、模式和进度，点击媒体卡片进入「正在播放」
- **音源管理**：粘贴 HTTP(S) 链接、JSON 或 JS 文件内容，查看名称、描述、版本、作者、主页；启用/禁用、上下移、二次确认删除，重启后保留
- **音源执行**：音源管理内可对启用音源运行「搜索自检（love）」；真实联网查询、检查歌曲字段，并调用首曲的直链与歌词处理器，结果显示摘要
- **设置页**：音源/缓存管理入口、缓存上限、仅 Wi-Fi 下载开关、薄荷绿/天空蓝/淡紫色强调色、版本与关于；设置自动保存，重启保留
- **交互**：页面轻量转场、按压与当前歌曲高亮、可换行的 Snackbar 提示；列表拖动与惯性滚动，底部「加载更多 / 下一页」继续浏览；切页保留位置且不中断播放
- **外观**：深色主题、三种可选强调色、中文文字、圆角卡片、启动图标；加载骨架、空状态引导和错误重试，跟随系统字体大小放大文字与控件，适配窄屏、横竖屏和系统安全区
- **返回键与手势**：编辑时先收系统键盘，再关闭编辑/确认、队列或设置说明，按访问历史返回上一个页面及滚动位置；无历史时回歌曲页再退出。Android 13+ 接入系统返回，Android 14+ 支持手势预览与取消

导入/启用只保存音源，不自动执行；点击搜索或自检才运行脚本并联网。普通 LX 音源通常没有搜索能力，不支持时会显示原因；目前只实现最小运行能力，并非所有社区脚本都可运行。目前播放或缓存音源搜索返回的 HTTP(S) 音频直链；库中保存的远程地址过期时需重新搜索选曲，已有缓存可离线播放。请只导入并运行可信来源的音源。
需要 Android 8.0 及以上、支持 OpenGL ES 3.0 的 arm64-v8a 手机或 x86_64 设备；不支持仅 32 位的设备。

## 安装

1. 打开 [Releases](https://github.com/JIAnnLee22/LXMusicC/releases)，选择正式版 `v1.1.0`，下载 `lxmusicc.apk`；若该版本尚未发布，请使用已发布的正式版或进度快照
2. 允许浏览器或文件管理器“安装未知应用”，打开 APK 完成安装；首次启动不需要音源或存储权限
3. 需要核对下载完整性时，对照同一 Release 的 `SHA256SUMS` 检查 APK 的 SHA-256

每个 `snapshot-*` 是约每 6 小时的进度快照（预发布），`v1.x` 才是正式版；平时提交不会产生安装包。版本变化见 [CHANGELOG](CHANGELOG.md)。

安装包目前在未配置专用发布证书时使用调试证书签名（应用本身不可调试），不同构建可能无法覆盖安装。若提示签名冲突，请勿直接卸载：卸载会丢失音源、收藏、历史、歌单、设置与缓存列表，公共音频可能仍在；需要保留这些数据时请保留旧版。相同签名且版本号不降低时可直接更新。只从本项目 Release 下载，SHA-256 仅核对完整性，不代替来源可信性。

## 使用

### 快速开始

1. **导入**：打开「设置 → 音源管理」，用系统键盘粘贴可信音源链接并导入、启用；没有音源时可先使用下方的公开预览示例。
2. **搜索与播放**：进入「搜索」，用系统键盘输入歌名/歌手，确认中文候选后回车，点击结果开始播放。
3. **缓存与后台控制**：「正在播放」中点击「缓存当前歌曲」，完成后可离线播放；切后台或锁屏，用系统媒体卡片或耳机按键控制。其它媒体浏览器也可浏览歌曲、选曲和控制播放。

### 详细用法

- 从底部切换页面，在歌曲页切换分类；设置页进入音源/缓存管理、直接设置缓存上限，向下滚动切换下载策略与主题，展开「关于」查看版本、兼容范围与致谢
- **导入音源**：在「设置 → 音源管理」点击地址框，使用系统键盘输入/粘贴 HTTP(S) 直链，回车或点击「导入」；也可复制整个 UTF-8 `.js` 文件文本，再点「粘贴导入」。无需存储权限，目前不提供文件选择器；地址框最多 2047 个 UTF-8 字节，完整脚本仍用「粘贴导入」
- **JSON 导入**：复制包含单个脚本的 `{"script":"完整 JS 文本"}`（也接受 `code` / `content` 字段或 JSON 字符串）；不是订阅列表，暂不支持压缩备份或批量音源包
- **管理音源**：点击启用状态切换，使用上移/下移调整顺序；删除需再次点击「确认删除」。超过三项时分页查看
- **运行示例**：复制仓库内 [`docs/examples/itunes-preview.js`](docs/examples/itunes-preview.js) 的完整文本导入并启用，到「搜索」输入 `love` 后点击搜索；也可在音源管理运行「搜索自检（love）」
- **输入搜索**：点击输入框打开系统键盘（如 Gboard、搜狗），拼音输入后选择中文候选，回车或点「搜索」；组合输入时先确认候选。点击文字定位光标，横向拖动选择文字；输入框激活后长按打开「全选 / 粘贴」，也可使用输入法剪贴板或「粘贴关键词」在选区插入/替换。软硬键盘共用系统编辑，关键词最多 255 个 UTF-8 字节；超长粘贴拒绝并提示
- **搜索结果**：每个启用源最多取前 30 条，最多聚合 240 首；使用上一页/下一页及上下滚动浏览，滑到底部可点「加载更多 / 下一页」。该按钮只翻到已有结果的下一页，不会无限请求音源。结果到达时逐步展示，个别音源失败不影响其他结果；取消后保留已到达的结果，重试使用上次关键词，搜索按钮使用当前输入
- **选曲与队列**：点击结果立即开始在线播放并进入「正在播放」；当前搜索页（最多八首）替换播放队列，从点击的歌曲开始播放；默认顺序播放，末曲结束后停止，也可在播放页切换模式。切回搜索保留关键词、结果和页码；新搜索不会改变队列，直到再次点击歌曲
- **收藏与歌单**：播放页向下滚动，点击「收藏 / 取消收藏」切换收藏；点击「添加到歌单」后选择歌单，重复添加不会增加条目。歌曲页「我的歌单」内创建歌单，进入歌单可重命名、二次确认删除歌单或移除歌曲；移除只影响当前列表，不删除缓存文件，也不影响其他歌单
- **库页搜索与播放**：在收藏、历史或歌单内输入歌名/歌手/专辑，点击搜索；歌单目录按歌单名称搜索。支持系统键盘中文候选、硬件键盘与选区粘贴，最多255字节；清除搜索恢复全部条目。点击库中歌曲以当前可见页（最多六首）替换播放队列，优先命中缓存
- **最近播放与保存**：实际开始播放才记录历史，失败加载不记；同一音源同曲不因音质/地址变化重复收藏或添加，历史再次播放置顶。收藏最多512首、历史保留最近200首、最多32张歌单/每张240首，音乐库最多1024首不同歌曲；歌单名去首尾空白、拒绝重名。等待「音乐库修改已保存」后可退出；清除应用数据或卸载会删除库数据，收藏/添加歌单本身不下载音频
- **播放控制**：在播放页暂停/继续、上下首及前后跳转 10 秒；点击或拖动进度条预览目标时间，松手后跳转。未知时长时不能拖动；时长以实际音频为准，切歌立即清除旧进度，加载失败后检查网络并点击播放重试。也可用通知栏、锁屏或耳机按键控制，点击媒体卡片返回应用
- **队列与模式**：上滑封面或点「上滑展开队列」打开队列，每页六首，点击歌曲立即切换；顶部向下滑动、收起按钮或返回键关闭。模式按钮依次切换顺序、列表循环、单曲循环、随机；列表循环首尾相接，单曲循环仅在自然结束时重播，手动上下首仍切歌。随机连续切歌不重复当前曲，上一首返回有界的随机历史；队列、当前歌曲、模式与进度会保存，冷启动恢复为暂停，不自动发声；随机历史不跨进程保存
- **其它 App / 车机调用**：兼容系统媒体浏览器的客户端可连接 LXMusicC，浏览「搜索结果 / 收藏 / 歌单 / 最近播放 / 播放队列」，选择歌曲后播放，也可在队列中选曲或跳转进度；客户端打开应用会进入「正在播放」。搜索结果仅来自本次运行在应用内已完成的搜索，冷启动为空；无内容时返回空列表。外部选曲采用该列表所在的最多240首窗口，不接受任意网址或外部修改队列；搜索结果更新后需刷新客户端列表。浏览音乐库会向已连接客户端公开这些歌曲信息，仅连接可信客户端
- **封面与系统输出**：音源提供封面时自动下载并复用，支持 JPEG/PNG；缺失、下载失败或格式不支持时显示音符占位，有地址时可点击重试。旧版示例需删除后重新导入本仓库最新示例才能返回封面；已缓存音频再次点缓存会补齐封面信息，不重复下载音频。封面缓存为应用私有数据、可能被新封面替换；不保证所有旧曲永久离线有封面。音量键始终调节媒体音量，输出设备在系统切换，无独立应用音量或设备选择器
- **离线缓存**：播放页点击「缓存当前歌曲」，完成后在系统文件管理器的 `Music/LXMusicC` 下查看文件。不会自动缓存整个队列；重复缓存会检查已有文件，不重新联网下载。下载失败可再次点击；退出应用界面会取消未完成的下载，后台音乐不受影响
- **缓存管理**：从「设置 → 缓存管理」或播放页进入；每页六首，点击歌曲即可离线播放，冷启动也无需重新搜索。支持二次确认单条删除/清空、检查外部删除的文件，以及 256/512/1024/2048 MiB 上限（默认 1024 MiB，重启保留）。满额会拒绝新下载，不自动删除旧曲；降低上限前需先释放足够空间。单曲最多 2 GiB、最多 512 条
- **仅 Wi-Fi 下载**：默认开启，仅允许已验证联网的非计费 Wi-Fi 缓存音频；移动网络、计费 Wi-Fi 或未确认联网时会拒绝，连接合适网络后再次点击缓存即可。下载中网络不再符合条件会在下一检查点中止并清理半成品，不自动续传；开关不限制搜索、封面或在线播放，也不影响已有缓存的离线播放。需要移动网络下载时在设置关闭此项，注意流量消耗
- **主题与保存**：在「设置 → 主题色」选择薄荷绿、天空蓝或淡紫色，全页即时生效；等待「设置已保存」后退出。保存失败会保留原设置，检查空间后点「重试保存设置」；设置文件异常会使用安全默认值，可手动保存重建
- **通知权限**：在「设置」查看通知状态，按需点击「允许通知 / 检查权限」或打开系统通知设置；拒绝后仍可播放，不会在启动时反复弹窗。媒体会话通知有系统授权豁免；若控制卡片不显示，可检查系统通知与播放通知渠道设置
- **存储权限**：Android 10 及以上缓存无需存储授权；Android 8/9 首次缓存需同意系统存储权限提示，再点击缓存重试。文件名中的路径/特殊字符会替换，超长名称会缩短，同名不同歌曲可能附数字。只管理本应用缓存，不扫描/导入整个公共音乐库；清除应用数据或卸载会失去缓存列表，公共音频可能仍保留
- **缓存被外部删除**：在缓存管理点「检查文件」后重新缓存；正在播放时删除文件可能影响继续播放或 seek，请重新选曲。缓存完成后再次选曲或暂停后继续会优先使用本地文件
- **后台与来电**：切后台、锁屏或按返回退出界面不会中断正在播放的音乐；来电暂时打断时暂停，焦点恢复后继续，也可手动点击播放。拔出有线耳机暂停，蓝牙媒体键由系统转发。强制停止应用/系统结束进程会停止播放；再次打开应用或由媒体客户端连接后，可恢复上次保存的队列和进度，需主动播放。正常播放进度约每5秒保存，刚选曲或强杀可能丢失最后尚未写入的操作；系统「强行停止」后，可能需要先手动打开应用才允许耳机键唤醒
- **网络失败**：断网、超时或音源不支持时显示原因；检查网络或调整音源后点击重试。取消立即停止接收本次结果，底层网络释放可能稍有延迟；详细结果可用 `adb logcat -s LXMusicC` 查看
- 示例使用 Apple 公开接口，仅返回约 30 秒音频预览，不是完整歌曲，不提供歌词；搜索列表展示完整曲目元数据时长，播放页显示实际预览时长。接口可能限流或因地区/网络不可达；搜索和自检不下载音频，在线播放消耗网络流量；手动缓存也仅保存该预览，不会变成完整歌曲
- 单次粘贴/下载上限 2 MiB，最多 32 个音源、脚本合计 8 MiB；失败会显示原因，可修改内容或检查网络后再次导入
- 优先使用 HTTPS；HTTP 链接不加密。链接应直接返回脚本文本或上述 JSON，而不是网页；非 ASCII 地址需百分号编码
- 上下滑动查看超出屏幕的内容；切换页面再返回，位置和选择仍在
- 键盘弹出时页面避让键盘，编辑区自动滚入可见范围；纵向拖动列表或输入框会收起键盘并继续滚动，横向拖动输入文字仍用于选区。旋转设备或分屏可继续输入；切后台保留正文，回来点击输入框继续。按系统返回键先收键盘，再返回上一层或退出
